# صفحة هبوط: معلم صفوف أولية وتأسيس ومتابعة دراسية وتحفيظ قرآن كريم بالرياض

صفحة هبوط تسويقية متكاملة، فائقة التجاوب مع كل أحجام الشاشات (Responsive)، ومزودة بهيدر عريض تفاعلي وأيقونة Favicon مخصصة لتبويب المتصفح.

---

## 🌟 أبرز التحديثات المنفذة في هذا الإصدار:

### 1. إضافة اللوجو في تبويب المتصفح (Favicon):
- تم تصميم وتوليد أيقونة تبويب المتصفح المخصصة (Favicon) بنفس هوية اللوجو المعتمدة (المصحف الشريف باللونين الزمردي والذهبي).
- الأيقونة متوفرة بصيغتين:
  - `favicon.svg` (أيقونة متجهة فائقة الدقة للشاشات الحديثة).
  - `favicon.png` (صيغة متوافقة 100% مع كافة متصفحات الويب).
  - كود مضمّن `data:image/svg+xml` داخل الصفحة ليضمن ظهور الأيقونة فوراً حتى عند فتح الملف مباشرة بدون خادم (`file:///`).

### 2. توسيع عرض الهيدر وتوفير مساحة مريحة (Header Spacing & Width):
- زيادة العرض الأقصى للهيدر وشريط الإعلانات إلى `max-w-[1540px]` لإعطاء رحابة إضافية على شاشات الكمبيوتر واللابتوب.
- تحريك اللوجو جهة اليمين وتزويده بهامش مريح (`pl-4 lg:pl-10 xl:pl-14`) لمنع أي تقارب أو تزاحم بين اللوجو وروابط الهيدر.
- موازنة وتوسيط روابط التنقل (`mx-auto px-4`) مما يمنح الهيدر مظهراً رحباً ومريحاً للعين.

### 3. معالجة تداخل النصوص (خصوصاً عنوان نور البيان):
- تم ضبط ارتفاع الأسطر لجميع العناوين إلى `line-height: 1.65 !important` مع `letter-spacing: normal !important`.
- في قسم **نور البيان**: تم تقسيم العنوان إلى كتلتين منفصلتين (`block`) بمسافة أمان رأسية واضحة (`pb-2 sm:pb-3` و `pt-1`) مع `leading-[1.75]`.
